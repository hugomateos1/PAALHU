# PAALHU — Practice 1

Authors: Hugo Mateos, Pablo Cuenllas, Álvaro Morillo.

Resources: dishes (main), drinks, setMenus, tables, customers, reservations, orders, reviews

PAALHU is an Indian restaurant in Madrid. The website shows the menu and lets customers book and order;
the API manages the restaurant's data.

## Run it

Requires Node 22.9+. Nothing else.

    npm install
    npm start          -> open http://localhost:3000

Optional: a `.env` file in the repo root with `PORT=3000` (it is git-ignored). Without it, the server uses port 3000.

## Resources

Every resource has an `id` generated by the server: it is never accepted from the client, and an `id` sent in a body is ignored.
Unknown fields are removed and never stored. Every field is required unless the table says "optional".

### dishes (main resource)

| Field | Type | Rules |
|---|---|---|
| id | number | server-generated, ignored if sent |
| name | string | required, 2–60 characters |
| category | string | one of `starters`, `curries`, `vegetarian`, `rice`, `breads`, `desserts` |
| price | number | from 0.50 to 50.00 |
| spiceLevel | number | whole number from 0 (not spicy 🍃) to 5 (very hot 🌶️🌶️🌶️🌶️🌶️), the same levels as the spice guide page |
| vegetarian | boolean | `true` or `false` only |
| available | boolean | `true` or `false` only (false = not served today) |

### drinks

| Field | Type | Rules |
|---|---|---|
| id | number | server-generated, ignored if sent |
| name | string | required, 2–60 characters |
| type | string | one of `lassi`, `tea`, `soft-drink`, `beer`, `water` |
| price | number | from 0.50 to 20.00 |
| alcoholic | boolean | `true` or `false` only |

### setMenus

| Field | Type | Rules |
|---|---|---|
| id | number | server-generated, ignored if sent |
| name | string | required, 2–60 characters |
| price | number | from 5.00 to 60.00 |
| service | string | one of `lunch`, `dinner` |
| weekdaysOnly | boolean | `true` or `false` only |
| active | boolean | `true` or `false` only |

### tables

| Field | Type | Rules |
|---|---|---|
| id | number | server-generated, ignored if sent |
| code | string | required, `M` followed by a number, e.g. `M7` |
| seats | number | whole number from 1 to 10 |
| joinable | boolean | `true` or `false` only (can be joined to the next table) |
| active | boolean | `true` or `false` only |

### customers

| Field | Type | Rules |
|---|---|---|
| id | number | server-generated, ignored if sent |
| name | string | required, 3–50 characters |
| email | string | required, valid email address, at most 100 characters |
| phone | string | required, 9 digits (spaces and a +34 prefix are accepted) |
| newsletter | boolean | `true` or `false` only |

### reservations

| Field | Type | Rules |
|---|---|---|
| id | number | server-generated, ignored if sent |
| name | string | required, 3–50 characters |
| phone | string | required, 9 digits |
| date | string | `YYYY-MM-DD`, a real date |
| time | string | `HH:MM`, 24 h |
| guests | number | whole number from 1 to 12 |
| status | string | one of `confirmed`, `seated`, `cancelled`, `no-show` |
| notes | string | optional, at most 500 characters |

### orders

| Field | Type | Rules |
|---|---|---|
| id | number | server-generated, ignored if sent |
| name | string | required, 3–50 characters |
| phone | string | required, 9 digits |
| type | string | one of `takeaway`, `delivery` |
| address | string | required when `type` is `delivery`, at most 200 characters |
| total | number | from 0.50 to 500.00 |
| status | string | one of `received`, `confirmed`, `ready`, `delivered`, `cancelled` |

### reviews

| Field | Type | Rules |
|---|---|---|
| id | number | server-generated, ignored if sent |
| author | string | required, 2–50 characters |
| rating | number | whole number from 1 to 5 |
| comment | string | required, 5–500 characters |
| published | boolean | `true` or `false` only |

## Endpoints

Every resource has the same five CRUD endpoints (`<resource>` = `dishes`, `drinks`, `setMenus`, `tables`,
`customers`, `reservations`, `orders`, `reviews`):

| Method | Path | Query params | Success | Errors |
|---|---|---|---|---|
| GET | /api/&lt;resource&gt; | | 200 | |
| GET | /api/&lt;resource&gt;/:id | | 200 | 404 |
| POST | /api/&lt;resource&gt; | | 201 + Location | 400 |
| PUT | /api/&lt;resource&gt;/:id | | 200 | 400, 404 |
| DELETE | /api/&lt;resource&gt;/:id | | 204 | 404 |

The main resource also has:

| Method | Path | Query params | Success | Errors |
|---|---|---|---|---|
| GET | /api/dishes | search, category, vegetarian, available | 200 | 400 |
| GET | /api/dishes/stats | | 200 | |

`/api/dishes/stats` returns `{ total, vegetarian, available, averagePrice, byCategory: { starters: 5, … } }`.

Other endpoints  in the project:

| Method | Path | Success | Errors |
|---|---|---|---|
| GET | /api/health | 200 | |
| GET | /api/chat/status | 200 | |
| POST | /api/chat | 200 | 400, 503 |

Errors: a 400 from a validator lists every problem at once: `{ errors: [ { field, message }, … ] }`.
Unknown routes answer a JSON 404. Server errors answer a JSON 500 without a stack trace.
